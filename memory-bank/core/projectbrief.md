# Project Brief

## プロジェクト名
opennask

## コア要件と目標
- 「30日でできる！OS自作入門」の川合秀実氏による `nask` アセンブラを、現代的な環境（Linux/CMake/Ninja）で動作するように再構築・互換性を持たせる。
- 自作 OS のブートストラップおよびアプリケーション開発に必要な x86 アセンブリのアセンブル機能を提供。

## プロジェクト範囲
- `nask` 互換のアセンブラエンジンの実装。
- OS 自作入門の各サンプルプロジェクト（Day 1 〜 Day 30）のビルド環境の構築。
- 補助ツール（objconv など）やライブラリ（golibc）の統合。

## 主要機能
- **x86 アセンブル**: MASM/NASM に近い `nask` 独自の構文をサポート。
- **CMake 統合**: 多数のサンプルプロジェクトを効率的にビルド・テスト・実行（QEMU）するためのビルドシステム。
- **rakusk の統合**: Raku 言語で実装された次世代アセンブラ `rakusk` をコアエンジンとして採用。

## 目標
- `nask` で書かれた既存の OS ソースコードを無修正（または最小限の修正）でアセンブルし、実機や QEMU で動作するイメージを生成できること。
- `gosk` (Go版アセンブラ) から `rakusk` (Raku版アセンブラ) への完全な移行。
