### CMakeLists.txt 自動生成 (`projects/cmake.sh`)
    - `projects/` ディレクトリ内の `.nas` ファイルを探索し、階層的な `CMakeLists.txt` を自動生成するためのスクリプトです。
    - 実行方法: `cd projects && bash cmake.sh`
    - **注意点**: 以前は `tee` コマンドを使用して生成される `CMakeLists.txt` の内容を標準出力にも表示していましたが、AI のトークン消費量を抑えるため、ファイルへのリダイレクト (`>` および `>>`) を使用するように変更されました (2025/04/07)。これにより、スクリプト実行時の標準出力は大幅に削減されましたが、`CMakeLists.txt` ファイル自体は正しく生成・更新されます。
    - このスクリプトは、さらに詳細なビルドルールを生成するために `projects/cmake_*.sh` スクリプト群を呼び出します。これらのサブスクリプトも同様に `tee` からリダイレクトに変更されています。
