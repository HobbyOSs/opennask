# Tech Context

## 使用技術
- **Raku**: 主要なアセンブラ `rakusk` の実装言語。
- **CMake**: プロジェクト全体の構成およびビルドシステムの管理。
- **Ninja**: 高速なビルド実行。
- **C/C++**: `golibc` やその他のツール群の実装に使用。
- **QEMU**: ビルドされた OS イメージの実行環境。

## 開発環境
- **OS**: Linux (Debian 等の Debian 系ディストリビューション)
- **パッケージマネージャー**: 
    - `zef`: Raku モジュールのインストール (`rakusk` 等)。
    - `apt`: CMake, Ninja, GCC 等のツールチェインの管理。

## 技術的な制約
- `nask` 独自のディレクティブ（`RESB`, `DB` などの特殊な用法）との完全互換性を維持する必要がある。
- 生成されたバイナリが期待されるバイナリデータと完全一致する必要がある。

## 依存関係
- **rakusk**: x86 アセンブラのコアエンジン。
- **objconv**: オブジェクトファイル変換用。
- **mtools**: OS イメージの生成および操作。
- **JSON::Fast**: `rakusk` が資源ファイルを読み込むために必要。
