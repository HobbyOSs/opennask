# Product Context

## プロジェクトの目的

新しい 80x86 アセンブラ `gosk` ([GitHub Issue](https://github.com/HobbyOSs/gosk/issues/12#issue-2974201766)) を含むビルドツールチェインを提供すること。

また、「30日でできる！OS自作入門」で作成されるような小さなOS (Haribote OS) 向けのサンプルプロジェクトを提供し、`gosk` を利用した開発環境を整備すること。

## 解決する問題

- 新しいアセンブラ `gosk` を利用して、Haribote OS のような学習用 OS を開発するための、完全なビルド環境とサンプルを提供する。これにより、学習者は `gosk` を使って OS 開発を体験できる。

## 動作方法

- `gosk` アセンブラ (開発中) を利用して、アセンブリ言語のソースコード (`.nas` 形式を想定) を 80x86 機械語コードに変換する。
- C コンパイラ (GCC/Clang) やリンカ (ld/lld) と連携し、OS イメージを構築するツールチェインを提供する。
- `projects/` ディレクトリには、「30日でできる！OS自作入門」の日ごとのサンプルコードが含まれており、これらを `gosk` を含むツールチェインでビルドし、QEMU で実行可能な OS イメージを作成する機能を提供する。
- ビルドシステム (CMake, Ninja/Make) を通じて、ツールチェインのビルドと、サンプル OS のビルド・実行を管理する。
